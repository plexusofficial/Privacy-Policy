FIREWATCH Privacy Policy
Last updated: October 16, 2026
FIREWATCH is an independent browser extension for viewing FACEIT CS2 player statistics and related performance information. It is not affiliated with or endorsed by FACEIT.

Information processed
The extension processes publicly accessible FACEIT player information and match statistics requested from the FACEIT Data API. If you provide a FACEIT API key, it is stored locally using Chrome extension storage and used to authenticate requests to the FACEIT API.

How information is used
Information is used to display player profiles, match history, map statistics, and session-related analysis within the extension. The extension does not require you to create a separate FIREWATCH account.

Sharing and external services
API requests are sent directly to https://open.faceit.com, including the API key as an authorization header. FACEIT may process those requests under its own privacy terms. This version of FIREWATCH does not send your API key or player statistics to a FIREWATCH-operated server, and does not use advertising or analytics SDKs.

Storage and retention
The API key is retained in Chrome's local extension storage until you remove it using the extension's Delete button or remove the extension. Player statistics are fetched for display; this version does not persist a separate database of player statistics.

Your choices
You may delete your saved API key from the extension popup or uninstall FIREWATCH. You may also review FACEIT's privacy terms for information processed by FACEIT.

Security
Requests to the FACEIT API use HTTPS. Browser extension local storage is not a secure vault; avoid using sensitive credentials other than the intended API key.

Changes
This policy may be updated if the extension's functionality or data practices change.

Contact
For privacy questions, contact the FIREWATCH developer through the support contact listed on the Chrome Web Store listing.
